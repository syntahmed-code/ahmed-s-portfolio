# Ahmed's Animated Portfolio

A modern, responsive, and animated portfolio website showcasing frontend development skills and projects.

## 🚀 Features

- **Smooth Animations**: Custom scroll animations using Lenis smooth scroll
- **Responsive Design**: Fully responsive across all devices (desktop, tablet, mobile)
- **Modern UI**: Clean, professional design with red accent colors
- **Security Features**: Protected against content theft and code inspection
- **Fast Performance**: Optimized for speed and performance
- **Interactive Elements**: Hover effects and smooth transitions

## 🎨 Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with CSS Grid and Flexbox
- **JavaScript**: Vanilla JS for animations and interactions
- **Lenis**: Smooth scrolling library
- **Google Fonts**: Allison, Inter, and Oswald fonts

## 📁 Project Structure

```
├── index.html          # Main HTML file
├── style.css           # All styles and responsive design
├── script.js           # JavaScript for animations and security
├── README.md           # Project documentation
├── My Photo.jfif       # Profile image
├── E- Commerce.png    # E-commerce project screenshot
└── Landing Page.png    # Brand identity project screenshot
```

## 🌐 Sections

1. **Hero**: Introduction with animated name and statistics
2. **About**: Personal background and skills
3. **Services**: Services offered (Web Development, Mobile Design, Performance)
4. **Vision**: Design philosophy and approach
5. **Tech Stack**: Technologies and tools used
6. **Projects**: Showcase of work (E-Commerce Platform, Brand Identity)
7. **Process**: Workflow and methodology
8. **Why Me**: Benefits of working together
9. **Contact**: Contact information and social links

## 🔧 Installation

1. Clone the repository
2. Open `index.html` in your browser
3. No build process required - it's a static site

## 📱 Responsive Breakpoints

- **Desktop**: 1200px+
- **Laptop**: 900px - 1199px
- **Tablet**: 768px - 899px
- **Mobile**: 600px - 767px
- **Small Mobile**: 400px - 599px

## 🔒 Security Features

- Right-click disabled
- Text selection disabled
- Copy/paste/cut disabled
- Dev tools shortcuts blocked
- Drag and drop disabled
- Debugger protection

## 🎯 Customization

### Colors
Edit CSS variables in `style.css`:
```css
:root {
    --black: #000000;
    --red: #d90429;
    --white: #f2f2f2;
    --muted: #777777;
}
```

### Content
Edit HTML in `index.html` to update:
- Personal information
- Project details
- Contact information
- Social links
